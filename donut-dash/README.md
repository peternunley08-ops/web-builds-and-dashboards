# 🍩 Donut Dash — Community 5K Fundraiser Website

Single-page event website and registration portal for **Donut Dash**, a student-led community run benefiting the **SLO Food Bank** in San Luis Obispo, CA.

## Highlights
- **Interactive Route Map:** Powered by **Leaflet.js 1.9.4**, rendering the race polyline and key checkpoints directly on the page with a direct Strava route link.
- **Dynamic Registration & Fee Calculator:** Live client-side validation for participant details and automatic fee calculation based on age tier.
- **Adaptive Theme Tokens:** Built with CSS Custom Properties supporting automatic `prefers-color-scheme` detection and manual dark/light mode toggling.
- **Zero Build Step:** Open `index.html` directly in any modern browser.
