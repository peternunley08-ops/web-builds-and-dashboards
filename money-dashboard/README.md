# 💳 Money Dashboard — Client-Side Budget & CSV Analyzer

A privacy-first, zero-network-call financial review web application in a single file (`index.html`).

## Features
- **Multi-Format CSV Parser:** Drag and drop **Chase** (credit or debit) and **PayPal** CSV exports; automatically normalizes dates, amounts, and merchant descriptions while skipping duplicates.
- **Rule-Based Auto-Categorization:** Categorizes transactions across 12 spending & income buckets with persistent per-transaction manual overrides.
- **Interactive SVG Donut & Budget Bars:** Live monthly breakdown with inline-editable category budgets stored in `localStorage`.
- **1-Click Demo Mode:** Click **"Load sample data"** in the header to explore the dashboard immediately with synthetic transactions.
